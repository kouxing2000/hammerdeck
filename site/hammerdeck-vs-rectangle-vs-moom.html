Hammerdeck, Rectangle or Moom: which Mac window tool fits

Rectangle if you want halves, thirds and drag-to-snap on a laptop or a single monitor, free. Moom if you want polished saved layouts and support back to macOS 10.13, for $15. Hammerdeck if you work across a big or several displays and want swaps, undo for every kind of move, and layouts that rebuild themselves, free.

This page is written by Hammerdeck's maker, so check the claims about the other two against their own pages, linked below. Each was read on 8 October 2026.

When Rectangle is the better pick

You use one screen, or a laptop plus one monitor, and want the standard sizes on keys with nothing else to learn. Rectangle is mature, popular and free, and it has a named key for each fraction, eighths included, where Hammerdeck has you pick cells on a grid.

When Moom is the better pick

You want saved layouts as the centre of how you work, a long-established paid app, or a Mac older than macOS 13.

When Hammerdeck is the better pick

  • You have an ultrawide or several displays and move windows between them all day; see moving windows between displays.
  • You want to swap everything on two displays in one go.
  • You want every window move, not just one window, to be undoable with one key.
  • You unplug a laptop daily and want the layout rebuilt when you come back; see putting windows back on reconnect.
  • You want to see what your automation did, and to read the code that did it.

What Hammerdeck does not do

  • Drag-to-snap. macOS 15 and later has it built in; on macOS 13 and 14 use the keys.
  • Always-on automatic tiling, where every new window is placed for you. That is a different kind of tool: look at AeroSpace or yabai.
  • Multi-step undo. One key undoes the most recent change, not a history.
  • The Mac App Store. It is a notarized download from this site, or Homebrew.

Hammerdeck is free and open source (GPL), notarized by Apple, and runs on macOS 13 and later.
