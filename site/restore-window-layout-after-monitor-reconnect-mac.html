Put your windows back when a monitor reconnects

Take a MacBook away from its desk and every window on the external display lands on the laptop screen. Plug it back in, and putting each one back where it was is your job.

The fix is to capture the arrangement once and let a rule rebuild it whenever that display connects. Hammerdeck does this for free, with no scripting: about two minutes of setup.

The external display is unplugged and everything piles onto the laptop; it is plugged back in and a rule puts all four windows back.

Set it up once

  1. With the monitor connected, arrange your windows on it the way you want them.
  2. Click Hammerdeck's menu bar icon and choose Rules…, then pick the recipe Arrange windows on dock (“Snap your windows into place when a display connects”). It fills in a connected display; pick the right one if you have several.
  3. Press Capture current layout. Every window on that display is recorded: its app, and its exact position and size.
  4. Save the rule. Press Test to watch it run without unplugging anything.

From then on, each time that monitor connects, by cable or through a dock, the windows go back. With several monitors, make one rule per display; a placement whose display is not connected is simply skipped.

What to expect

  • Windows are matched by app. If an app has several windows, each one is placed, but which goes where follows window order. To pin a particular window, add part of its title in the rule's JSON editor.
  • Apps that are not running are skipped, and the run says which ones in Hammerdeck's local log, along with any window macOS refused to move.
  • A rule can do more than arrange windows. The same trigger can open an app, set the wallpaper, or run any macOS Shortcut, in a chain.
  • Moving windows needs the Accessibility permission; Hammerdeck explains why on first launch before macOS asks.

And by hand, in between

For the moves you make all day, ⌃⌥⌘] throws a window to the next display and ⌃⌥⌘Z undoes the last move. More in moving a window to another display.

Other ways to do it

  • Moom ($15) can apply a saved layout automatically when displays are added or removed, and several smaller paid apps do this one job.
  • Hammerspoon (free, open source) can do anything here if you write the Lua yourself. Hammerdeck grew out of years of Hammerspoon scripts, and exists for the people who would rather not.

Hammerdeck, Rectangle or Moom compares them in more detail.

Hammerdeck is free and open source (GPL), notarized by Apple, and runs on macOS 13 and later.
