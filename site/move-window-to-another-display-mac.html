Move a window to another display with a keyboard shortcut on Mac

macOS ships no keyboard shortcut for it, at any version through macOS 27. Its own window shortcuts (macOS 15 and later) cover halves, quarters, fill and centre on the display the window is already on.

Three ways to get one: bind the Window menu's Move to command yourself, use Rectangle, or use Hammerdeck, which also swaps everything on two displays in one go and undoes either move with one key.

1. The built-in way: App Shortcuts

With a second display connected, most apps' Window menu has a Move to <display name> item. macOS lets you give any menu item a shortcut:

  1. Open System Settings › Keyboard › Keyboard Shortcuts › App Shortcuts.
  2. Click +, choose All Applications.
  3. Under Menu Title, type the item exactly as it appears, display name included, for example Move to DELL U3224KB.
  4. Press the keys you want, and add one more entry for each other display.

It costs nothing, and it has three limits: the title must match character for character, so a renamed or replaced monitor breaks it; you need one shortcut per display rather than one for “the next one”; and apps without a standard Window menu don't have the item at all.

2. With Hammerdeck: one key, any app, and undo

Hammerdeck is a free, open-source menu bar app. Window Snap is on from the first launch:

  • ⌃⌥⌘] throws the focused window to the next display, ⌃⌥⌘[ to the previous one. The window keeps its relative size and position, and the pointer rides along so you can keep working in it.
  • ⌃⌥⌘Z (Window Rewind) puts it back.
  • Swap windows between displays moves everything on your display to the other one and everything there to yours, rescaled to fit. It has no default shortcut, as it is an occasional move: run it from the menu bar, or give it any key in Settings. With three or more displays it asks which one to swap with.

One key throws a window to the other display and back. The second half is a rule rebuilding the layout on replug, covered in putting windows back when a monitor reconnects.

Every shortcut can be changed in Settings, and each press flashes the name of the action that ran, so a wrong key is obvious. It needs the Accessibility permission to move windows, and explains why before macOS asks.

3. Other apps that do it

  • Rectangle (free, open source, macOS 14 and later) has next and previous display shortcuts, alongside its halves and thirds.
  • Moom ($15, macOS 10.13 and later) has a Move to Other Display action you can put on a key.

If a display throw is all you need, any of them will do. Hammerdeck is built for the setup where you do it all day: the swap, the undo, and layouts that rebuild themselves. The side-by-side comparison lists what each one does.

Hammerdeck is free and open source (GPL), notarized by Apple, and runs on macOS 13 and later.
